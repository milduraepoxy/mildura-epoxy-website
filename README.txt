MILDURA EPOXY - GITHUB PAGES WEBSITE

This is the GitHub Pages-ready version of the Mildura Epoxy website.

Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do not upload this folder itself as a nested folder.

Required structure:
  index.html
  CNAME
  .nojekyll
  photos/
    (all gallery photos)

The standalone HTML file has intentionally been removed. GitHub Pages only needs the normal index.html and photos folder.

Custom domain:
  milduraepoxy.com.au

The CNAME file is already included for the custom domain.
